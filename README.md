# Ragdoll Fighting Game

A 3D local multiplayer fighting game built in **Unity**, focused on physics-based ragdoll combat, arena knockouts, lives, UI feedback, sound effects, and match flow.

## Creators

Development made by:

- Nicolás González
- Camilo Carvajal

## About

This project is an arcade-style fighting prototype where players battle inside an arena using ragdoll-based movement and punches. The game includes a main menu, loading flow, fight scene, player HUD, lives system, hit effects, death effects, music, and match start/end panels.

The goal of the project is to explore:
- physics-driven combat
- local multiplayer gameplay
- UI/UX flow for matches
- audio feedback and visual effects in Unity

## Features

- Physics-based ragdoll characters
- Punch hit detection
- Life system per player
- Knockout by accumulated hits
- Life loss when falling out of the arena
- Player HUD with heart icons
- Start panel and end-of-match panel
- Menu music and fight music
- Hit, damage, and death effects
- Local multiplayer setup for up to 4 players
